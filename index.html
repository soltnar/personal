Настройки и синхронизация

Обновление проходной

Отчёт читает сохранённые дни из базы. После 05:00 МСК автоматически загружаются только отсутствующие и неуспешные дни. При сбое загрузка продолжается с сохранённой страницы; автоматические повторы выполняются в течение дня. Готовые дни не перезагружаются. Для принудительного обновления используйте кнопку ниже.

Принудительное обновление доступно владельцу через Google.

Смена учитывается на точке последнего выхода за рабочие сутки 04:00–03:59. Записи без выхода требуют проверки.

Вход Saby: подключение и пользователи

Подключение интерактивной авторизации

В настройках внешнего приложения Saby разрешите интерактивный OAuth-вход. Адрес возврата:

https://soltnar.github.io/personal/saby-callback.html

Секрет не возвращается в браузер после сохранения. Не используйте сервисный ключ вместо client_secret.

Пользователи Saby

После первого входа сотрудник появляется здесь без доступа. Разрешите вход и назначьте предприятия и разделы. Google-права по email не переносятся автоматически.

Список предприятий берётся из справочника. Блокировка пользователя завершает его сеансы приложения.

Добавить или изменить Google-доступ

Для каждого предприятия назначайте разделы отдельно. Без назначения сотрудник не получит данные. Вход — через Google с указанным email.
